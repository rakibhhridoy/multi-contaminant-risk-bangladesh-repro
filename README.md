# Hasan et al. — *Cumulative multi-contaminant groundwater exposure in Bangladesh*

Complete analysis code and data for the manuscript submitted to *Science of the Total Environment* (2026). Running `bash run_all.sh` on a clean install regenerates every numerical claim, every supplementary table, and every figure panel in the paper.

- **Code repository:** https://github.com/rakibhhridoy/multi-contaminant-risk-bangladesh-repro
- **Code + data archive (this bundle, incl. large CMIP6/GRACE rasters):** Zenodo, DOI [10.5281/zenodo.20383702](https://doi.org/10.5281/zenodo.20383702)
- **Original sample dataset:** Zenodo, DOI [10.5281/zenodo.19148957](https://doi.org/10.5281/zenodo.19148957)

---

## 1. Quick start

```bash
git clone https://github.com/rakibhhridoy/multi-contaminant-risk-bangladesh-repro.git
cd multi-contaminant-risk-bangladesh-repro

# Python 3.11+ recommended
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Download the large rasters from Zenodo (CMIP6 ~1.3 GB + GRACE ~850 MB)
# and extract them under data/external/ — see Section 3 below.

# Run the full pipeline (~15-25 min depending on hardware)
bash run_all.sh
```

Outputs land in `output/tables/` (52 CSVs) and `output/figures/` (PNG + TIFF).

A pre-computed copy of `output/tables/` is shipped with this bundle so that figures-only or downstream re-analysis can be done without re-running the full pipeline.

### Shared `config.py`
`config.py` lives at the bundle root and is imported by every script as `from config import …`. Every tier script adds the bundle root to `sys.path` via `Path(__file__).parent.parent.parent`, so scripts work both from the bundle root and from inside their tier folders.

## 3. Downloading the large external rasters

Two folders are deliberately excluded from this code bundle and the GitHub repository because they exceed GitHub's per-file limits. Both are archived on Zenodo and must be downloaded once before running the climate/satellite scripts.

### 3a. CMIP6 precipitation ensemble (~1.3 GB)

Six CMIP6 models × two SSPs from WorldClim 2.1 (statistically downscaled to 2.5 arc-minutes, 2041–2060 window):

```
wc2.1_2.5m_prec_EC-Earth3-Veg_ssp245_2041-2060.tif
wc2.1_2.5m_prec_EC-Earth3-Veg_ssp585_2041-2060.tif
wc2.1_2.5m_prec_GFDL-ESM4_ssp585_2041-2060.tif
wc2.1_2.5m_prec_IPSL-CM6A-LR_ssp245_2041-2060.tif
wc2.1_2.5m_prec_IPSL-CM6A-LR_ssp585_2041-2060.tif
wc2.1_2.5m_prec_MIROC6_ssp245_2041-2060.tif
wc2.1_2.5m_prec_MIROC6_ssp585_2041-2060.tif
wc2.1_2.5m_prec_MPI-ESM1-2-HR_ssp245_2041-2060.tif
wc2.1_2.5m_prec_MPI-ESM1-2-HR_ssp585_2041-2060.tif
wc2.1_2.5m_prec_MRI-ESM2-0_ssp245_2041-2060.tif
wc2.1_2.5m_prec_MRI-ESM2-0_ssp585_2041-2060.tif
```

Source of record: https://www.worldclim.org/data/cmip6/cmip6_clim2.5m.html
Extract all eleven `.tif` files directly into `data/external/cmip6/` (no nested subdirectory).

### 3b. GRACE/GRACE-FO satellite gravimetry (~850 MB)

Two NASA EarthData products:

- `GRACEDADM_CLSM025GL_7D` — NASA/GSFC 7-day groundwater storage percentile, 0.25° resolution, 345 weekly granules, 2018-06 to 2024-12
- `TELLUS_GRAC-GRFO_MASCON_CRI_GRID_RL06.3_V4` — JPL CRI mascon LWE thickness, 255 monthly granules, 2002-04 to 2026-03 (single multi-decadal NetCDF: `GRCTellus.JPL.200204_202603.GLO.RL06.3M.MSCNv04CRI.nc`)

Source of record: https://earthdata.nasa.gov (free login required). Extract into:

```
data/external/grace_fo/GRACEDADM_CLSM025GL_7D/    ← 345 .nc4 granules
data/external/grace_fo/TELLUS_GRAC-GRFO_MASCON_CRI_GRID_RL06.3_V4/   ← 1 .nc file
```

The Zenodo data archive provides a single tarball with the exact directory structure expected by the scripts.

## 5. Run order and dependencies

`run_all.sh` runs scripts in dependency order. The minimum spanning order is:

```
spatial_aggregation.py          ← writes T2_zone_population_weighted_stats.csv (consumed by every DALY script)
    ↓
daly_estimation_corrected.py    ← headline 941,884 figure
    ↓                            ↓                  ↓                 ↓
tornado            synergy_bound       idw_spatial_cv     interventions_corrected (imports daly_estimation_corrected)
```

Tiers T3, T4, T5 are independent of T2 and can be run in any order.
