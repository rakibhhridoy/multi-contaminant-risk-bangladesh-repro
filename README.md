# Hasan et al. — *Cumulative multi-contaminant groundwater exposure in Bangladesh*

Complete analysis code and data for the manuscript under review at *Journal of Hazardous Materials Advances* (2026; HAZADV-D-26-01282).

Reproducing the paper takes two commands, because the analysis and the figures have different toolchains:

| | command | needs | produces |
|---|---|---|---|
| **Analysis** | `bash run_all.sh` | Python 3.11+ | every numerical claim and supplementary table (`output/tables/`) |
| **Figures** | `cd figures_d3 && ./render.sh` | Node 22+, Inkscape | all 20 figures as SVG/PDF/PNG (`figures_d3/`) |

Run the analysis first: the figure pipeline reads the tables it writes.

- **Code repository:** https://github.com/rakibhhridoy/multi-contaminant-risk-bangladesh-repro
- **Code + data archive (this bundle, incl. large CMIP6/GRACE rasters):** Zenodo, DOI [10.5281/zenodo.20383702](https://doi.org/10.5281/zenodo.20383702)
- **Original sample dataset:** Zenodo, DOI [10.5281/zenodo.19148957](https://doi.org/10.5281/zenodo.19148957)

## 1. Quick start

```bash
git clone https://github.com/rakibhhridoy/multi-contaminant-risk-bangladesh-repro.git
cd multi-contaminant-risk-bangladesh-repro

# Python 3.11+ recommended
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# Download the large rasters from Zenodo (CMIP6 ~1.3 GB + GRACE ~850 MB)
# and extract them under data/external/ — see Section 3 below.

# 1. Analysis (~15-25 min depending on hardware)
bash run_all.sh

# 2. Figures (~2 min; needs Node 22+ and Inkscape)
cd figures_d3 && npm install && ./render.sh
```

The analysis writes `output/tables/` (58 CSVs). The figure pipeline writes
`figures_d3/{data,svg,pdf,png}/` — one JSON per figure, then the rendered artwork.

A pre-computed copy of `output/tables/` is shipped with this bundle, as is
`figures_d3/data/*.json`, so the figures can be rebuilt, or downstream re-analysis
done, without re-running the full pipeline.

### Shared `config.py`
`config.py` lives at the bundle root and is imported by every script as `from config import …`. Every tier script adds the bundle root to `sys.path` via `Path(__file__).parent.parent.parent`, so scripts work both from the bundle root and from inside their tier folders.

Two folders are deliberately excluded from this code bundle and the GitHub repository because they exceed GitHub's per-file limits. Both are archived on Zenodo and must be downloaded once before running the climate/satellite scripts.

```
wc2.1_2.5m_prec_IPSL-CM6A-LR_ssp245_2041-2060.tif
wc2.1_2.5m_prec_IPSL-CM6A-LR_ssp585_2041-2060.tif
wc2.1_2.5m_prec_MIROC6_ssp245_2041-2060.tif
wc2.1_2.5m_prec_MIROC6_ssp585_2041-2060.tif
wc2.1_2.5m_prec_MPI-ESM1-2-HR_ssp245_2041-2060.tif
wc2.1_2.5m_prec_MPI-ESM1-2-HR_ssp585_2041-2060.tif
wc2.1_2.5m_prec_MRI-ESM2-0_ssp245_2041-2060.tif

```

Source of record: https://www.worldclim.org/data/cmip6/cmip6_clim2.5m.html
Extract all eleven `.tif` files directly into `data/external/cmip6/` (no nested subdirectory).

### 3b. GRACE/GRACE-FO satellite gravimetry (~850 MB)

Two NASA EarthData products:

- `GRACEDADM_CLSM025GL_7D` — NASA/GSFC 7-day groundwater storage percentile, 0.25° resolution, 345 weekly granules, 2018-06 to 2024-12
- `TELLUS_GRAC-GRFO_MASCON_CRI_GRID_RL06.3_V4` — JPL CRI mascon LWE thickness, 255 monthly granules, 2002-04 to 2026-03 (single multi-decadal NetCDF: `GRCTellus.JPL.200204_202603.GLO.RL06.3M.MSCNv04CRI.nc`)

Source of record: https://earthdata.nasa.gov (free login required). Extract into:

```
data/external/grace_fo/GRACEDADM_CLSM025GL_7D/    ← 345 .nc4 granules
data/external/grace_fo/TELLUS_GRAC-GRFO_MASCON_CRI_GRID_RL06.3_V4/   ← 1 .nc file
```

The Zenodo data archive provides a single tarball with the exact directory structure expected by the scripts.

## 5. Run order and dependencies

`run_all.sh` runs scripts in dependency order. The minimum spanning order is:

```
spatial_aggregation.py          ← writes T2_zone_population_weighted_stats.csv (consumed by every DALY script)
    ↓
daly_estimation_corrected.py    ← headline 941,884 figure
    ↓            ↓              ↓            ↓                    ↓                        ↓
tornado   synergy_bound   idw_spatial_cv   gbd_reconciliation   mn_weight_sensitivity   interventions_corrected
                                                                                        (imports daly_estimation_corrected)
```

Within T1, `paired_seasonal_transfer.py` must run before `climate_transfer_ensemble.py`,
which consumes `T1_seasonal_transfer.csv`. Tiers T3, T4, T5 are independent of T2 and
can be run in any order.

Then the figures, which read the tables the above produced:

```
figures_d3/export_data.py + export_si.py   → figures_d3/data/*.json
    ↓
fig1-6.mjs, s1-13.mjs, ga.mjs (node)       → figures_d3/svg/*.svg
    ↓
inkscape                                    → figures_d3/{pdf,png}/
```

`figures_d3/render.sh` runs all three stages.

## 6. Determinism and what varies between runs

Every script is seeded at `config.RANDOM_STATE = 42`, and re-running the pipeline
reproduces all headline numbers exactly: 941,884 / 462,318 / 2.04x, 165,969,178,
59.9% joint exceedance, +74% national arsenic, 1.31x at the mild manganese weight.

One script is **not** bit-for-bit deterministic. `scripts/t4_tipping/tipping_points.py`
resamples for its bootstrap confidence intervals without a fixed seed, so a re-run
reproduces `T4_bistability_all_contaminants.csv` with small differences:

| quantity | behaviour across runs |
|---|---|
| `bimodal` flag | stable — 30/30 rows, every run |
| `delta_bic` | stable to within 0.7 BIC units |
| `delta_bic_ci_lo` / `_ci_hi` | vary by up to ~100 BIC units |
| `saddle_original` | 27 of 30 rows identical; Fe2+ (Intermediate, Medium_Deep) and PO43- (Overall) vary in the third decimal (max 0.025) |
| significant cascades (`T4_cascade_conditional.csv`) | stable — 10 of 36 pairs, no significance flips; conditional probabilities vary by <= 0.011 |

**No claim in the manuscript depends on the parts that vary.** The four arsenic
antimodes the text quotes (27.094, 22.562, 0.143, 0.178 µg/L) are identical on
every run. The only text claim touching the bootstrap is that every depth-zone
combination returns delta-BIC > 10; the observed minimum is 20.0, a margin of 10.0
against a run-to-run drift of 0.7. The tables shipped in `output/tables/` are the
exact ones the submitted figures were built from, so `figures_d3/render.sh` on a
clean checkout reproduces the manuscript artwork byte-for-byte from them.

## Revision v3 — 2026-09-01 (JHMA round, HAZADV-D-26-01282)

This version reproduces the **revised** manuscript. Three changes affect reported
numbers; everything else is unchanged.

**1. Guideline thresholds are now current WHO health-based values**
(`config.py`, `scripts/t3_copula/copula_analysis.py`)

| contaminant | was | now | basis |
|---|---|---|---|
| manganese | 0.4 mg/L | **0.08 mg/L** | WHO 2021 provisional guideline value (WHO/HEP/ECH/WSH/2021.5). The 2011 value is superseded. |
| iron | 0.3 mg/L | **2.0 mg/L** | WHO provisional health-based value. 0.3 mg/L is the EPA secondary MCL, an aesthetic threshold. |

Joint exceedance for ≥2 contaminants: 57.4% → **59.9%**. Manganese exceedance
43.3% → 75.5%; iron 86% → 61%. The hazard index and DALY results are unaffected,
since those use reference doses rather than guideline values, and the copula
dependence results are unaffected because copulas are fitted on ranks.

**2. Seasonal transfer coefficients are now within-well paired differences**
(`scripts/t1_climate/paired_seasonal_transfer.py`, new; runs before
`climate_transfer_ensemble.py` in `run_all.sh`)

The earlier coefficients contrasted unpaired dry- and wet-campaign medians, which
confounded seasonal change with which wells each campaign visited. They are now
computed as within-well paired differences over the 810 locations sampled in both
campaigns, with Wilcoxon signed-rank tests and bootstrap intervals over pairs.

WHO guideline crossings by 2050 under SSP5-8.5: 3 → **1**. National median arsenic
increase: +132% → **+74%**. The unpaired table is preserved as
`output/tables/T1_seasonal_transfer_UNPAIRED.csv` for comparison.

**3. Figure 1 and the graphical abstract no longer contain a non-data schematic**
(`fig1_variants.py`, `scripts/t4_tipping/graphical_abstract_svg.py`)

The stylised double-well curve was removed from Figure 1 and replaced in the
graphical abstract with the empirical phosphate-response curve computed from the
data. Every panel in the revised manuscript is now computed directly from data.

**Audit script.** `scripts/rerun_jhma_audits.py` reproduces every number quoted in
the revision's audit findings: the CMIP6 CV reconciliation, spatially blocked
cross-validation of the phosphate model, the benchmark sensitivity of joint
exceedance, the DALY aggregation comparison, and the manganese threshold.

**Note on cross-validation.** `partial_info_phosphate.py` uses randomly partitioned
folds. The revised manuscript reports **spatially blocked** validation as primary
(0.5° grid blocks): AUC 0.65 → 0.73, ΔAUC +0.08 [+0.05, +0.13]. Run
`scripts/rerun_jhma_audits.py` to reproduce the blocked figures; the random-fold
values (0.69 → 0.77) are reported alongside in the manuscript for comparison.

## Revision v4 — 2026-09-03 (JHMA resubmission)

Additions since v3. No previously reported number changes.

**1. The figures are now built by `figures_d3/`, not by `run_all.sh`**

All 20 figures moved to a D3 pipeline (Python exports JSON, D3 renders SVG through
jsdom, Inkscape converts). The v3 README claimed `bash run_all.sh` regenerated
every figure panel; that has not been true since the figures were rebuilt, and
Section 4 now documents the actual pipeline and its Node 22+ / Inkscape
requirements. The superseded matplotlib scripts are retained for provenance and
are no longer invoked.

**2. New: manganese disability-weight sensitivity (Fig S13, R2.1)**

`scripts/t2_health/mn_weight_sensitivity.py` sweeps the GBD disability weight
assigned to manganese-attributable neurodevelopmental impairment and reports the
multi-contaminant / arsenic-only DALY ratio as a continuous function of it. It
reproduces the published contaminant-specific model exactly at DW = 0.043
(605,443 DALYs, 1.31x) and gives 3.23x at the moderate/severe upper anchor
(DW = 0.361); dose-addition at 2.04x sits inside that range, with the crossover at
DW = 0.165.

**3. New: GBD reconciliation wired into `run_all.sh`**

`scripts/t2_health/gbd_reconciliation.py` (SI Table S3) was present but never
driven; it now runs in sequence and ships its output table.

**4. Determinism documented**

Section 6 is new. It records exactly which quantities vary between runs of
`tipping_points.py`, and shows that no manuscript claim depends on them.
